# DigiTech Academy — Data Analytics Bootcamp (Cohort 1)

This repository contains class materials for the **Data Analytics** program 
under **DigiTech Academy**, covering:

- 📊 **Excel** — DigiTech Excel Class
- 📈 **Power BI** — DigiTech PowerBI Class
- 🗄️ **SQL** — DigiTech SQL Class

## 📁 Structure
| Folder | Description |
|---|---|
| `DigiTech Excel class/` | Excel exercises, datasets, and slides |
| `DigiTech PowerBI Class/` | Power BI projects and dashboards |
| `DigiTech SQL Class/` | SQL scripts and practice databases |

## 👥 Cohort
This material is for **Cohort 1** students of the DigiTech Academy 
Data Analytics program.

## 📌 Usage
Clone or download this repo to access all class resources in one place:
\```
git clone https://github.com/<your-username>/digitech-academy-data-analytics-cohort1.git
\```
